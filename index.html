Image sources from dmaorg all contain a 12-character string that precedes the actual file name. Each of these strings contain letters and numbers in such a pattern that they can be split in in half and used as HEX codes for colors.

Here are those HEX codes. I started with the image at the very bottom of the page and worked my way back up the site in chronological order of the uploads. The first file source 'ff1640a042d' has been split into two, 6-character strings and shows two different colors, as shown below in the gradient.
